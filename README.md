## Ver localmente

```bash
node serve.js
```

Abra http://localhost:4174

## Trocar fotos

As fotos atuais são de banco de imagens gratuito (Pexels) e servem de marcador.
Substitua os arquivos em `assets/img/` mantendo o mesmo nome e a mesma proporção.

## Antes de ir ao ar

- Trocar o domínio de exemplo `https://www.valdugaacos.com.br/` em `index.html`
  (`canonical`, `og:url`), `robots.txt` e `sitemap.xml`.
